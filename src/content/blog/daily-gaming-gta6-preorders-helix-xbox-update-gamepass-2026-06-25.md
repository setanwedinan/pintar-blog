**25 Juni 2026** — Hari ini menjadi salah satu hari terbesar di dunia gaming tahun ini dengan dibukanya pre-order **Grand Theft Auto VI**, pengumuman harga **Xbox Project Helix**, dan berbagai update fitur konsol Xbox. Berikut rangkuman lengkapnya.

## 🎮 GTA 6 Pre-orders Resmi Dibuka — Semua yang Perlu Kamu Tahu

**25 Juni 2026** menjadi tanggal yang ditunggu-tunggu: **Rockstar Games** resmi membuka pre-order untuk **Grand Theft Auto VI**, yang akan rilis **19 November 2026** untuk PlayStation 5 dan Xbox Series X|S.

### Detail Harga dan Edisi:

- **Standard Edition:** $79.99 — kenaikan harga signifikan dari standar $69.99
- **Ultimate Edition:** detail lengkap telah diungkap termasuk bonus pre-order eksklusif
- **Physical Edition:** kontroversi! "Edisi fisik" GTA 6 ternyata hanya **berisi download code di dalam box** — tidak ada disc fisik. Dilansir dari **Pure Xbox**, keputusan ini memicu perdebatan sengit di kalangan gamer yang menginginkan media fisik sesungguhnya.

**TechRadar** melaporkan bahwa pre-order langsung diserbu, dengan beberapa pengecer mengalami gangguan situs di menit-menit awal pembukaan. Harga $79.99 menandai era baru harga game AAA, diikuti oleh judul-judul besar lainnya.

## 🖥️ Xbox Project Helix: Harga Resmi Diumumkan, Reaksi Gamer Terbelah

**Xbox Project Helix** — konsol next-gen Microsoft — akhirnya mengumumkan harga resminya. Dilansir dari **ScreenRant**, pengumuman ini datang di tengah spekulasi sengit tentang seberapa mahal konsol generasi berikutnya.

Reaksi gamer terbelah: sebagian menganggap harga tersebut wajar mengingat spesifikasi yang ditawarkan, sementara yang lain mengingatkan bahwa **PS6** dan **Nintendo Switch 2** juga akan segera hadir, menambah tekanan kompetitif. Pekan lalu, Xbox CEO Asha Sharma sempat mengatakan bahwa "sulit membayangkan gamer menghabiskan Rp50 juta untuk konsol baru" — pernyataan yang kini diuji dengan harga resmi Project Helix.

## 🔧 Xbox Insider Update: Gamertag Lebih Panjang, Cloud Play, dan Game Hubs 360

**Microsoft** merilis update besar untuk Xbox Insiders dengan empat fitur baru:

1. **Gamertag Lebih Panjang** — dari 12 menjadi **15 karakter**, memberikan lebih banyak fleksibilitas untuk personalisasi
2. **Xbox 360 Game Hubs** — game Xbox 360 kini memiliki **dedicated Game Hubs** sendiri, lengkap dengan pencapaian dan info komunitas
3. **Cloud Play Saat Update** — pemain bisa langsung **streaming game via cloud** saat game sedang mengunduh atau mengupdate. Dilansir dari **Kotaku** dan **GameSpot**, ini adalah solusi untuk salah satu frustrasi terbesar gamer: harus menunggu update besar selesai sebelum bisa bermain
4. **Prompt Cloud Saat Update** — sistem akan menawarkan opsi streaming jika game membutuhkan update besar

## ⚠️ ASA Larang Iklan Xbox Game Pass

**UK Advertising Standards Authority (ASA)** secara resmi melarang iklan **Xbox Game Pass** karena dianggap menyesatkan. Masalahnya: iklan tersebut menampilkan konten in-game yang tidak tersedia di versi Game Pass. Dilansir dari **GamesHub**, keputusan ini menjadi pukulan bagi strategi pemasaran Game Pass di Inggris.

## 🎭 Ori Creator: "Game Pass Bisa Berhasil, Tapi..."

**Ori and the Blind Forest** creator memberikan pernyataan menarik tentang **Xbox Game Pass**. Dalam wawancara dengan **IGN India**, ia mengatakan bahwa Game Pass sebenarnya model yang bisa berhasil, namun ada faktor-faktor yang membuatnya tidak optimal — termasuk struktur kompensasi developer dan ekspektasi pemain.

## 📋 Game Pass — 'Tears of Metal' dan Kabar Lainnya

- **'Tears of Metal'** — game bergaya "Scottish Dynasty Warriors" akan hadir di Game Pass bulan depan. Dilansir dari **Pure Xbox**, game ini menawarkan pertarungan brutal ala Skotlandia kuno
- **Developer game day-one Game Pass** — studio di balik salah satu judul rilis-harian Game Pass dikabarkan akan tutup. Dilansir dari **TrueAchievements**, berita ini menambah kekhawatiran tentang keberlanjutan model bisnis Game Pass bagi developer indie
- **RV There Yet?** — sebuah glitch Game Pass memungkinkan pemain memainkan game ini lebih awal

## ⚠️ Peringatan Layoff di Xbox

**Game Developer** melaporkan bahwa mantan karyawan Xbox memperingatkan potensi **balas dendam** dalam gelombang PHK yang dikabarkan akan datang. Mereka mendesak karyawan saat ini untuk mendokumentasikan pengalaman mereka sebagai bentuk perlindungan.

## 📦 Deals: Seagate Xbox Expansion Card Diskon

**Windows Central** melaporkan bahwa semua tiga varian **Seagate Storage Expansion Card for Xbox Series X|S** sedang diskon besar-besaran di Prime Day. Solusi plug-and-play ini memungkinkan gamer menambah penyimpanan tanpa harus menghapus game favorit.
