## Top Story: GPT-6 Sol dan Luna (1.560 poin, 750 komentar)

OpenAI memperkenalkan [GPT-6 Sol dan Luna](https://openai.com/index/introducing-gpt-6-sol-and-luna/) dan dalam hitungan jam langsung naik ke posisi puncak Hacker News dengan 1.560 poin dan 750 komentar. Diskusinya ramai — [thread-nya](https://news.ycombinator.com/item?id=49805509) layak dibaca kalau mau lihat reaksi komunitas developer terhadap rilis ini.

## Juga Panas di HN Hari Ini

- **[Claude Code reads AGENTS.md only when telemetry is on](https://blog.szypowi.cz/p/claude-code-reads-agents.md-only-when-telemetry-is-on/)** — 199 poin, 73 komentar. Penulisnya menemukan bahwa Claude Code baru membaca file AGENTS.md ketika telemetry dinyalakan. Topik yang sensitif bagi pengguna coding agent, karena banyak yang menaruh instruksi penting di file itu.
- **[Jev in 25 Lines of Python](https://www.nobodywho.ai/posts/jev-in-25-lines/)** — 138 poin, 48 komentar. Demo bahwa inti sebuah parser bisa ditulis sangat ringkas.
- **[Z80 REPL](https://abagames.github.io/z80-repl/index.html)** — 66 poin, 7 komentar. REPL untuk prosesor legendaris Z80 yang bisa dipakai langsung dari browser — nostalgia buat yang pernah main dengan mesin 8-bit.
- **[The GitHub wiki is an anti-pattern](https://michaelheap.com/github-wiki-is-an-antipattern/)** — 29 poin, 19 komentar. Argumen kenapa wiki bawaan GitHub justru jadi tempat dokumentasi yang mudah terlupakan.

## Kenapa Ini Penting

Dua dari lima story teratas menyentuh workflow developer sehari-hari: satu soal cara coding agent membaca instruksi proyek (AGENTS.md), satu lagi soal di mana dokumentasi tim sebaiknya hidup. Rilis besar seperti GPT-6 memang menarik perhatian, tapi perdebatan soal tooling seperti ini biasanya yang paling lama relevannya.
