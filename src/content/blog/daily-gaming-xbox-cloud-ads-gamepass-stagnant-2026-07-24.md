## 🔥 TOP STORY: Xbox Uji Coba Cloud Gaming Gratis dengan Iklan — Game Pass Tak Lagi Diperlukan

**Microsoft** mengumumkan langkah revolusioner: **Xbox Cloud Gaming gratis berbasis iklan** kini mulai diuji coba untuk Xbox Insiders. Layanan ini memungkinkan siapa pun untuk melakukan streaming game Xbox ke perangkat mereka **tanpa perlu berlangganan Game Pass Ultimate**.

**Bagaimana cara kerjanya:**
- Iklan akan diputar **sebelum sesi game dimulai** — bukan di tengah permainan
- Sesi cloud gaming gratis dibatasi **1 jam per sesi**
- Tersedia untuk Xbox Insiders terlebih dahulu
- Game yang bisa di-stream termasuk game yang sudah dimiliki pengguna maupun katalog Game Pass tertentu

**Microsoft menegaskan lima prinsip:**
1. Iklan tidak akan mengganggu gameplay
2. Tidak ada iklan di game berbayar penuh
3. Pengguna Game Pass tetap mendapatkan pengalaman bebas iklan
4. Opsi bebas iklan akan selalu tersedia
5. Pengembang tetap mendapatkan kompensasi yang adil

Kabar ini dikonfirmasi langsung melalui **Xbox Wire** dan dilaporkan oleh **The Verge**, **Engadget**, **Gizmodo**, **PCMag**, dan **VideoCardz**.

Langkah ini dipandang sebagai upaya Microsoft untuk **memperluas jangkauan Xbox Cloud Gaming ke pasar massal** — terutama di negara-negara dengan penetrasi konsol rendah tapi koneksi internet baik. Dengan model gratis beriklan, Xbox bisa menjangkau miliaran pengguna smartphone dan tablet yang sebelumnya tidak bisa mengakses ekosistem Xbox.

## 📊 Game Pass Subscribers Stagnan di 30 Juta — Target 100 Juta Masih Jauh

**Tech Insider** melaporkan bahwa pertumbuhan **Xbox Game Pass** mengalami stagnasi. Angka subscriber dilaporkan tetap di **30 juta** — sebuah angka yang tidak berubah signifikan dalam beberapa waktu terakhir.

**Mengapa ini penting:**
- Target awal Microsoft adalah **100 juta subscriber** pada 2030
- Dengan stagnasi di 30 juta, target tersebut semakin sulit dicapai
- Model cloud gaming gratis dengan iklan bisa menjadi strategi untuk mendorong pertumbuhan

Analis mencatat bahwa stagnasi ini terjadi meskipun Microsoft terus menambahkan game-game blockbuster ke layanan — termasuk Activision Blizzard titles dan day-one releases. Faktor utama yang disebutkan adalah **jenuhnya pasar langganan game** di negara maju, di mana sebagian besar gamer sudah memiliki ekosistem langganan yang mereka sukai.

**Sumber:** [Tech Insider](https://www.techinsider.com/)

## ⚠️ Halo: Campaign Evolved — Pemain Premium Terkunci di Hari Peluncuran

Peluncuran **Halo: Campaign Evolved** — remake dari Halo: Combat Evolved yang sangat dinantikan — tidak berjalan mulus. Ribuan pemain yang membayar lebih untuk **akses early access** justru tidak bisa memainkan game tersebut di hari peluncuran.

**Apa yang terjadi:**
- Pemain yang membeli **Premium Upgrade** ($30-$40) untuk akses awal pada hari Kamisz
- Namun pada saat peluncuran, banyak yang mendapati game **terkunci** atau mengalami error
- **Halo Support** mengakui masalah dan mengatakan sedang "menyelidiki"
- Diduga terkait dengan **Xbox Live Services yang down** pada hari yang sama

**Insider Gaming** dan **GameSpot** melaporkan bahwa masalah ini memicu kemarahan di komunitas Halo. Pemain yang membayar ekstra untuk bermain lebih awal justru mendapatkan pengalaman yang lebih buruk daripada mereka yang sabar menunggu rilis reguler.

**Yang juga menarik:**
- Game ini mendukung **pre-load** dan file size sudah diumumkan
- Versi PC melalui **ROG Xbox Ally X** menunjukkan performa yang solid (Steam Deck HQ)
- Masalah ini terjadi setelah Microsoft sebelumnya memamerkan backward compatibility Halo di PC

**Sumber:** [Insider Gaming](https://insider-gaming.com/) · [GameSpot](https://www.gamespot.com/) · [Halo Support](https://support.halowaypoint.com/) · [GAMES.GG - Preload Guide](https://www.games.gg/) · [Steam Deck HQ](https://steamdeckhq.com/)

## 🚗 Forza Horizon 5 Director: "Game Pass Belum Sepenuhnya Menepati Janji"

Dalam sebuah wawancara yang mengejutkan, **direktur Forza Horizon 5** secara terbuka menyatakan bahwa **Xbox Game Pass belum sepenuhnya menepati janjinya**.

Menurut sang director:
> "Game Pass adalah model yang luar biasa untuk konsumen, tapi belum sepenuhnya memberikan value yang dijanjikan kepada developer."

Pernyataan ini memicu diskusi hangat di industri gaming. **Forza Horizon 5** adalah salah satu game first-party Xbox paling sukses, dan komentar dari developernya sendiri tentang Game Pass tentu berbobot.

Beberapa poin yang disebutkan:
- **Day-one releases** di Game Pass mungkin mengkanibal penjualan ritel
- Model kompensasi untuk developer masih perlu diperbaiki
- Meskipun pemain banyak, dampak finansial untuk studio tidak selalu sebanding

Pernyataan ini menjadi kontras dengan optimisme Microsoft tentang pertumbuhan Game Pass dan cloud gaming.

**Sumber:** [Game Informer](https://www.gameinformer.com/)

## 🎬 Avatar Legends: The Fighting Game — Shock Delay di Xbox

**Avatar Legends: The Fighting Game** mengalami **penundaan mendadak di Xbox** hanya beberapa jam sebelum jadwal rilis. **IGN** melaporkan bahwa game yang dikembangkan oleh Maximum Entertainment ini tiba-tiba ditunda di platform Xbox tanpa penjelasan resmi yang jelas.

Sementara itu, versi PlayStation dan PC tetap rilis sesuai jadwal. Spekulasi awal mengaitkan penundaan ini dengan masalah teknis pada versi Xbox, namun belum ada konfirmasi resmi dari penerbit.

**Sumber:** [IGN](https://www.ign.com/)
