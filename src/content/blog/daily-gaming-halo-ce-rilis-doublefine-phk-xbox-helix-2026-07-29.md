## 🎮 Gaming Daily — 29 Juli 2026

Hari yang besar bagi para penggemar Halo! **Halo: Campaign Evolved** akhirnya resmi rilis dan tersedia di **Xbox Game Pass**. Tapi tidak semua berita positif — **Double Fine** harus memberhentikan 23 karyawan setelah berpisah dari Xbox, dan laporan baru menunjukkan Game Pass gagal mencapai target subscriber. ## 🔫 Halo: Campaign Evolved Resmi Rilis — Tersedia di Game Pass Hari Ini!

**Halo: Campaign Evolved** akhirnya hadir! Game yang dinanti-nantikan ini resmi dirilis pada **29 Juli 2026** dan langsung tersedia di **Xbox Game Pass** sebagai day-one title.

**Yang perlu diketahui:**
- Tersedia di **Xbox Series X|S**, **PC (Steam & Microsoft Store)**, dan **PS5**
- **Digital Foundry** memuji skalabilitas game — berjalan mulus dari PS5 Pro hingga Xbox Series S dengan Unreal Engine 5
- Banyak **Master Chief skins gratis** untuk pemain Game Pass
- **PCMag** bertanya: "Is It Time to Resubscribe?" — merujuk pada kualitas Halo CE sebagai alasan kuat untuk berlangganan Game Pass

Namun, **Notebookcheck** melaporkan bahwa **player count di Steam dan Xbox** masih di bawah ekspektasi pra-rilis, menimbulkan kekhawatiran tentang daya tarik game ini di luar basis penggemar Halo.

**Game Pass juga sudah mengonfirmasi 4 game day-one untuk Agustus 2026**, menunjukkan pipeline yang tetap solid meskipun banyak kontroversi.

## 🔴 Double Fine PHK 23 Karyawan Pasca Berpisah dari Xbox

Kabar sedih dari industri gaming: **Double Fine Productions**, studio di balik **Psychonauts 2**, harus melakukan **PHK terhadap 23 karyawan** — beberapa bulan setelah resmi **berpisah dari Xbox**.

**Polygon**, **Kotaku**, dan **Game Informer** melaporkan bahwa langkah ini adalah konsekuensi dari divestasi Double Fine dari Xbox yang diumumkan beberapa waktu lalu. Studio yang didirikan oleh **Tim Schafer** ini kini harus beroperasi secara independen tanpa dukungan finansial Microsoft.

Ini menjadi pukulan telak bagi industri game independen — Double Fine adalah salah satu studio kreatif paling dihormati, dan PHK ini menunjukkan bahwa bahkan studio ternama pun tidak kebal dari gejolak industri.

🔗 [Sumber: Polygon](https://www.polygon.com/double-fine-layoffs-xbox/) · [Kotaku](https://kotaku.com/double-fine-lays-off-employees-amid-xbox-separation-2000719885) · [Game Informer](https://gameinformer.com/2026/07/28/double-fine-announces-layoffs-following-split-from-xbox)

## 🔄 Xbox Helix & Steam — Mengapa Strategi Ini Tak Lagi Masuk Akal

**Windows Central** menerbitkan analisis mendalam tentang **Xbox Helix** — platform cloud gaming Xbox — dan hubungannya dengan Steam. Menurut analis, strategi multiplatform Xbox yang semakin agresif membuat Helix kehilangan identitas. Jika game Xbox sudah tersedia di Steam, PS5, dan Switch, apa gunanya Helix?

Pertanyaan besarnya: apakah Xbox akan mengubah strategi Helix atau justru menghentikannya sama sekali?

## 📉 Game Pass Gagal Capai Target Subscriber — Analis: "Orang Tidak Main Banyak Game"

Sebuah laporan baru dari **GamesRadar** dan **TheGamer** mengungkapkan bahwa **Xbox Game Pass gagal mencapai target subscriber** karena alasan yang mengejutkan: **kebanyakan orang tidak memainkan banyak game**.

Analis industri menjelaskan bahwa model langganan "all-you-can-eat" seperti Game Pass hanya menguntungkan bagi gamer hardcore yang menyelesaikan banyak game. Sebagian besar pemain hanya menyelesaikan 1-2 game per tahun, membuat Game Pass tidak efisien secara finansial bagi mereka.

Ini menjadi analisis lanjutan dari krisis Game Pass yang sudah diberitakan sebelumnya — kali ini dengan data konkret tentang perilaku pemain.

🔗 [Sumber: GamesRadar](https://www.gamesradar.com/platforms/xbox/xbox-game-pass-failed-to-hit-subscriber-targets-because-most-people-dont-play-lots-of-games-says-analyst-and-going-indie-wont-save-it-i-dont-see-a-solution/) · [TheGamer](https://www.thegamer.com/xbox-game-pass-could-have-worked/)
