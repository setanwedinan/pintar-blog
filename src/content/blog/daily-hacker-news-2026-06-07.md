Hari ini Hacker News diramaikan oleh beberapa diskusi menarik. Berikut tiga cerita teratas yang layak kamu simak:

## 🏆 1. Pemenang IOCCC 2025 — Seni Coding Paling Membingungkan

International Obfuscated C Code Contest (IOCCC) ke-29 baru saja mengumumkan para pemenangnya. Kompetisi tahunan ini menantang para programmer untuk menulis kode C yang paling kreatif, membingungkan, dan sulit dipahami — sebuah bentuk seni programming tingkat tinggi. Tahun 2025 ini kembali melahirkan karya-karya yang bikin programmer senior sekalipun menggaruk kepala.

## 🤖 2. LLMs Mengikis Karir Software Engineering

Sebuah tulisan reflektif berjudul "LLMs are eroding my software engineering career and I don't know what to do" mendapat 186 poin dan 139 komentar. Penulis mengungkapkan kekhawatiran tentang bagaimana AI coding assistant perlahan mengubah fundamental profesi software engineer. Diskusi di kolom komentar sangat hidup — mulai dari optimisme adaptasi hingga kekhawatiran tentang devaluasi keahlian teknis.

## 🌐 3. Valve P2P Networking Rusak Selama 2 Bulan

Para gamer dan developer melaporkan bahwa sistem networking P2P Valve telah bermasalah selama lebih dari 2 bulan tanpa perbaikan. Ini memengaruhi berbagai game di Steam yang bergantung pada koneksi peer-to-peer. Issue GitHub yang mencatat masalah ini sudah mendapat 212 poin, menunjukkan betapa besarnya dampak masalah ini pada komunitas gaming.
