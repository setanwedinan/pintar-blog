## Otomatisasi Opt-Out dari 500+ Situs Data Broker — Proyek Open Source yang Viral di Hacker News

Hari ini di [Hacker News](https://news.ycombinator.com/), story paling populer adalah proyek **auto-identity-remove** karya Stephen Thorn — sebuah tools open-source yang mengotomasi proses penghapusan data pribadi dari ratusan situs data broker.

![HN Top Story](https://news.ycombinator.com/)

### Apa Itu Data Broker?

Data broker adalah perusahaan yang mengumpulkan, menyimpan, dan menjual informasi pribadi Anda — mulai dari nama, alamat, nomor telepon, hingga riwayat pembelian. Situs people-search seperti WhitePages, Spokeo, BeenVerified, dan ratusan lainnya memperdagangkan data ini tanpa sepengetahuan Anda.

### Tentang auto-identity-remove

**auto-identity-remove** adalah runner otomatis yang:

- 🔒 **Menghapus data pribadi** dari 30+ situs people-search secara otomatis
- 🔄 **Berjalan terjadwal** setiap bulan untuk memastikan data tidak muncul kembali
- 📝 **Menggunakan Playwright** untuk mengotomasi proses opt-out di setiap situs
- 🆓 **Sepenuhnya open-source** dan gratis digunakan

Proyek ini sudah mendapatkan **283 stars** dan **8 forks** di GitHub, menjadi salah satu solusi paling populer untuk perlindungan privasi personal.

### Mengapa Ini Penting?

1. **Data Anda Diperdagangkan Tanpa Izin** — Sebagian besar orang tidak sadar bahwa data mereka sudah tersebar di ratusan situs data broker
2. **Manual Opt-Out Sangat Melelahkan** — Menghapus data dari 500 situs satu per satu bisa memakan waktu berminggu-minggu
3. **Data Broker Terus Menambah Data Baru** — Bahkan setelah dihapus, data bisa muncul kembali dari sumber lain
4. **Risiko Keamanan Nyata** — Data yang tersebar di banyak situs meningkatkan risiko identity theft dan social engineering

### Reaksi Komunitas

Thread Hacker News ini mendapatkan **213 points** dan **71 komentar** dalam 2 jam, menunjukkan betapa besar kebutuhan komunitas tech akan solusi seperti ini. Banyak komentar yang berbagi pengalaman serupa tentang kesulitan menghapus data pribadi dari internet.

### Cara Menggunakan

Proyek ini tersedia di GitHub dan bisa dijalankan secara lokal atau melalui GitHub Actions untuk otomasi penuh. Dokumentasi lengkap tersedia di repository.

### Kesimpulan

Di era di mana data pribadi menjadi komoditas, proyek seperti ini menjadi semakin penting. Alih-alih harus membayar jasa penghapusan data yang mahal, tools open-source ini memberdayakan individu untuk mengambil kendali atas privasi mereka sendiri.
