## TL;DR

- **Xbox** merespons rumor bahwa Game Pass akan kehilangan game day-one pada 2027, menurut Kotaku dan Gamespot.
- **Game Pass Wave 2 September** diumumkan secara resmi oleh IGN, mencakup Black Ops 6, Minecraft Dungeons 2, Gears of War: E-Day, dan RuneScape: Dragonwilds.
- Rumor baru menyebut **Game Pass overhaul** pada 2027 dengan harga $12.99 untuk tier beriklan, sementara tier lain dilaporkan turun ke $19.99 tanpa game day-one.
- Game Pass kehilangan **11 game lagi** di bulan September, menurut ScreenRant.
- **Fable** diklaim oleh pengembangnya sebagai RPG yang "stick the landing," lapor Polygon.
- **CTO Xbox** memperingatkan bahaya pembelian kode game palsu.
- **Microsoft Flight Simulator** mengumumkan Airbus A380 sebagai marketplace eksklusif.

## 📢 Xbox Resmi Beri Tanggapan soal Rumor Day-One Game Pass

Kotaku dan Gamespot melaporkan bahwa Xbox secara resmi merespons rumor yang beredar bahwa Game Pass akan kehilangan game day-one pada tahun 2027. Rumor ini pertama kali muncul dari forum ResetEra dan menyebar luas ke berbagai outlet game. Tanggapan resmi Xbox mengonfirmasi bahwa rumor tersebut tidak benar, setidaknya untuk saat ini.

Sumber: [Kotaku](https://kotaku.com/xbox-responds-to-rumors-that-game-pass-is-losing-day-one-new-games-in-2027-200073) · [Gamespot](https://www.gamespot.com/articles/microsoft-reacts-to-xbox-game-pass-rumor-that-could-change-the-ser)

## 📋 Game Pass Wave 2 September Resmi Diumumkan

IGN mengkonfirmasi lineup **Xbox Game Pass September Wave 2** yang mencakup sejumlah judul besar:

- **Black Ops 6** — Call of Duty terbaru
- **Minecraft Dungeons 2** — sekuel dari game dungeon crawler populer
- **Gears of War: E-Day** — tersedia day-one di Game Pass Ultimate dan PC Game Pass
- **RuneScape: Dragonwilds** — tambahan baru untuk penggemar RPG

Softonic dan XboxAchievements juga mengkonfirmasi lineup yang sama. Stuff.tv menyebut bahwa jika rumor day-one benar terjadi, hal itu bisa "membunuh layanan berlangganan."

Sumber: [IGN](https://www.ign.com/articles/xbox-game-pass-september-2026-wave-2-lineup-announced) · [Softonic](https://en.softonic.com/articles/xbox-game-pass-reveals-september-wave-2-black-ops-6-minecraft-dunge) · [XboxAchievements](https://www.xboxachievements.com/news/xbox-game-pass-september-2026-wave-two-runescape-dragonwilds-d)

## 💰 Rumor Overhaul Game Pass 2027: Tier Iklan $12.99

Beberapa outlet melaporkan rumor dari ResetEra tentang **overhaul besar Game Pass pada 2027**:

- Wccftech menyebut rumor harga Game Pass turun menjadi **$19.99 per bulan**, tetapi dengan konsekuensi game day-one dihapus dari tier tersebut.
- A 90s Kid dan Daily Express melaporkan rumor **tier beriklan seharga $12.99** yang lebih murah.
- Tech Insider mengaitkan rumor ini dengan laporan **pendapatan Game Pass turun 10%** dalam periode tertentu.

Penting dicatat bahwa semua ini masih berupa rumor. Xbox telah merespons dan membantah bahwa game day-one akan dihapus, namun tidak secara spesifik membantah keberadaan tier beriklan.

Sumber: [Wccftech](https://wccftech.com/xbox-game-pass-rumor-price-drop-day-one-games-removed/) · [A 90s Kid](https://www.a90skid.com/resetera-rumor-alleges-2027-xbox-game-pass-overhaul-12-99-ad-tier/) · [Tech Insider](https://tech-insider.org/xbox-game-pass-leak-revenue-decline-2026/)

## 🗑️ Game Pass Kehilangan 11 Game di September

ScreenRant melaporkan bahwa Game Pass kehilangan **11 game gratis** di bulan September 2026 — satu lebih banyak dari yang dilaporkan kemarin (10 game). Judul-judul yang keluar tidak disebutkan dalam cuplikan RSS, sehingga kami tidak menuliskan daftar spesifik.

Sumber: [ScreenRant](https://screenrant.com/xbox-game-pass-september-2026-wave-2/)

## 🧙 Fable: "Stick the Landing"

Polygon melaporkan bahwa pengembang **Fable** — RPG besar Xbox berikutnya — berjanji game ini akan "stick the landing." Judul yang sudah lama dinantikan ini menjadi salah satu amunisi first-party Xbox untuk memperkuat katalog eksklusifnya.

Sumber: [Polygon](https://www.polygon.com/fable-rpg-reboot-xbox-ending/)

## 🛡️ CTO Xbox Peringatkan Kode Game Palsu

Pure Xbox melaporkan bahwa **CTO Xbox** mengeluarkan peringatan tentang bahaya pembelian kode game palsu. Peringatan ini muncul di tengah maraknya penjualan kode game tidak resmi yang merugikan konsumen dan pengembang.

Sumber: [Pure Xbox](https://www.purexbox.com/news/2026/09/xbox-cto-warns-against-the-dangers-of-buying-fraudulent-game-c)

## ✈️ Microsoft Flight Simulator Umumkan Airbus A380

Microsoft Flight Simulator mengumumkan **Airbus A380** sebagai konten marketplace eksklusif. Pesawat superjumbo ini menjadi tambahan yang dinantikan oleh komunitas simulator penerbangan.

Sumber: [Flightsimulator.com](https://www.flightsimulator.com/msfs-announces-the-airbus-a380/)
