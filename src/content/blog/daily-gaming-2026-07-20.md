## 🎮 Gaming Daily — 20 Juli 2026

Hari yang sangat panas di dunia gaming! Sebuah laporan dari **Bloomberg** mengguncang industri: **para pimpinan studio Xbox Game Studios dilaporkan "membenci" Game Pass** dan menganggap layanan berlangganan itu telah menghancurkan nilai game mereka. Bahkan, Bloomberg memprediksi Xbox mungkin akan **menghentikan game day-one di Game Pass**. Plus, Xbox resmi mengkonfirmasi kembalinya eksklusif, Halo Campaign Evolved siap rilis, dan masih banyak lagi!

## 🔥 KRISIS GAME PASS: Pimpinan Studio Xbox "Benci" Layanan Sendiri

Ini adalah berita **terbesar hari ini** yang diberitakan oleh hampir semua outlet gaming terkemuka. **Bloomberg** via jurnalis veteran **Jason Schreier** mengungkap bahwa **banyak pimpinan di Xbox Game Studios "absolutely detest" (benci sekali) Game Pass**.

**Apa yang sebenarnya terjadi?**

Menurut laporan yang dikutip oleh **GameReactor**, **Destructoid**, **GamingBolt**, **Windows Central**, **WCCFTech**, **VICE**, **Yahoo Finance**, dan puluhan outlet lainnya:

- Para pemimpin studio merasa **Game Pass telah "menghancurkan nilai" game mereka**
- Game AAA yang sebelumnya dijual $70 kini tersedia dengan harga "receh" melalui langganan
- **Penjualan game individual merosot** drastis karena pemain cukup menunggu game masuk ke Game Pass
- Ada **ketegangan internal yang parah** antara tim bisnis Xbox yang mendorong Game Pass dan tim studio yang merasa dirugikan

**Windows Central** melaporkan bahwa Schreier, dalam podcast terbarunya, mengungkapkan bahwa para pemimpin studio ini bertanya: **"Kenapa saya harus menghabiskan 5 tahun membuat game hanya untuk diberikan secara gratis di hari pertama?"**

**Yahoo Finance** menulis analisis mengapa Xbox tetap mendorong Game Pass meskipun para pimpinan studio membencinya — jawabannya: **strategi langganan adalah visi Phil Spencer dan manajemen puncak Microsoft untuk masa depan gaming**, terlepas dari penolakan internal.

## 📉 Bloomberg: Xbox Mungkin Hentikan Day One Game Pass

Masih dari laporan yang sama, **Jason Schreier memprediksi bahwa Xbox mungkin akan menghentikan rilis day-one untuk game first-party di Game Pass**.

Dalam analisisnya:

- **Para pemimpin Xbox** secara pribadi mendorong perubahan ini
- **Model day-one di Game Pass** dianggap tidak berkelanjutan secara bisnis — biaya produksi game AAA terus naik, sementara pendapatan dari Game Pass belum tentu bisa menutupinya
- **VICE** dan **Technobezz** mengutip prediksi Schreier bahwa perubahan ini bisa terjadi dalam waktu dekat

Jika ini benar-benar terjadi, ini akan menjadi **perubahan kebijakan paling signifikan dalam sejarah Xbox modern** — mengingat day-one Game Pass adalah fitur unggulan yang membedakan Xbox dari PlayStation.

Beberapa analis memperingatkan bahwa jika day-one dihapus, **nilai Game Pass akan berkurang drastis**, berpotensi menyebabkan **gelombang pembatalan langganan**.

## 🎮 Xbox Konfirmasi Eksklusif Kembali, Tapi Tidak Semua Game

**IGN** melaporkan bahwa **eksekutif Xbox telah kembali menegaskan komitmen mereka terhadap game eksklusif** — meskipun dengan beberapa catatan penting.

Poin-poin utama:

- **Matthew Ball dan Matt Booty** mengonfirmasi bahwa **permanen eksklusif akan memainkan peran penting** dalam strategi gaming Microsoft
- Game seperti **Gears of War: E-Day dan Clockwork Revolution** dikonfirmasi sebagai eksklusif Xbox/PC
- Namun, **tidak semua game akan tetap eksklusif** — Xbox masih mempertimbangkan port PS5 untuk beberapa judul
- **"It Isn't Something Carved in Stone"** — Push Square mengutip pernyataan Xbox yang masih belum jelas soal port PS5 di masa depan

**Niche Gamer** menulis bahwa Xbox "bringing exclusives back," sementara **Polygon** masih mempertanyakan nasib game-game Fallout yang baru diumumkan — apakah mereka akan eksklusif Xbox atau tidak?

**Kotaku** juga menulis opini bahwa game **Fallout fan-made** justru lebih menarik daripada apa yang Xbox tawarkan saat ini — menunjukkan bahwa kepercayaan komunitas terhadap strategi Xbox masih rendah.

## ⚔️ Halo Campaign Evolved Rilis Bulan Ini

**Times of India** melaporkan bahwa **Halo Campaign Evolved** akan diluncurkan akhir bulan ini. Detail yang diketahui:

- **Premium Upgrade Edition** tersedia untuk pemain yang sudah memiliki base game atau bermain melalui Xbox Game Pass
- Mode campaign baru yang memperluas universe Halo
- Early access untuk pemain tertentu

Ini adalah konten Halo baru yang dinanti-nantikan setelah sekian lama — terutama di tengah krisis Game Pass, Xbox membutuhkan rilis besar seperti ini untuk menjaga momentum.

## 🔄 Akun Xbox 25 Tahun Dipulihkan Microsoft

**Tweaktown** melaporkan kisah menarik: **Microsoft memulihkan akun Xbox berusia 25 tahun** yang nilainya mencapai ribuan dolar setelah pemiliknya kehilangan akses.

Joshua Khane kehilangan akses ke akun Microsoft/Xbox lamanya yang berisi **game-game lawas yang sekarang sangat berharga** — beberapa di antaranya sudah tidak bisa dibeli lagi. Setelah perjuangan panjang dengan layanan pelanggan, Microsoft akhirnya memulihkan aksesnya.

Kisah ini juga mengungkap **bahaya gaming digital** — ketika layanan tutup atau akun hilang, ribuan dolar investasi game bisa lenyap dalam sekejap. Ini menjadi pengingat penting tentang **pentingnya menjaga keamanan akun** dan perlunya **regulasi yang melindungi konsumen** di era game digital.

🔗 [Baca selengkapnya di Tweaktown](https://www.tweaktown.com/news/112671/microsoft-restores-access-to-25-year-old-xbox-account-worth-thousands-of-dollars-exposes-pitfalls-of-digital-gaming/index.html)
