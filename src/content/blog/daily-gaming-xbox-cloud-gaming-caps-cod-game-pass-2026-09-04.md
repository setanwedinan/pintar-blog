**TL;DR:** Kabar besar (dan pahit) bagi pelanggan Game Pass: mulai November, cloud gaming tidak lagi tanpa batas. Xbox memperkenalkan kuota bulanan per tier — 15 jam untuk Ultimate, 10 jam untuk Premium, 5 jam untuk Essential — dengan opsi membeli jam tambahan. Kebijakan yang pada 2020 dijual sebagai "akses tanpa batas" kini resmi berakhir, meski Microsoft mengklaim hanya 4% pelanggan yang terdampak. Di sisi ceruk: Game Pass menyambut salah satu entri Call of Duty paling underrated, dan 15+ game baru rilis di Xbox hari ini termasuk satu day-one release.

## ☁️ Era Cloud Gaming "Unlimited" Resmi Berakhir

Ini keputusan besar yang digemakan hampir semua outlet game hari ini: **Xbox mengumumkan pembatasan jam bulanan untuk cloud gaming di semua tier Game Pass, efektif November** (Game Informer, Ars Technica, The Verge, Engadget, dan belasan lainnya).

Struktur kuotanya:

| Tier                              | Kuota Cloud per Bulan |
| --------------------------------- | --------------------- |
| Game Pass Ultimate ($22,99/bulan) | **15 jam**            |
| Game Pass Premium                 | **10 jam**            |
| Game Pass Essential               | **5 jam**             |

Ars Technica mengingatkan konteks pahitnya: pada 2020, Microsoft mengumumkan bahwa Game Pass Ultimate akan mencakup **akses tanpa batas** ke layanan cloud gaming yang saat itu baru diluncurkan. Enam tahun kemudian, janji itu dicabut. Aftermath menyindir keras dengan judul "Microsoft Just Found Yet Another Way To Enshittify Xbox Game Pass", dan Game Spot bermetafora: "Xbox claws back one of the biggest benefits of Game Pass Ultimate."

## 💰 Beli Jam Tambahan & Opsi Baru Tanpa Game Pass

Ada dua jalur lanjutan yang menarik:

**Pertama, top-up berbayar.** Begitu kuota habis, pelanggan bisa membeli kredit tambahan untuk membuka lebih banyak waktu (Cinelinx, Briefs Finance). Xbox belum mengonfirmasi harganya — perusahaan hanya menyebut akan memberi "more information" nanti (Windows Central). PCMag membingkainya lugas: ingin bermain lebih lama? Bayar ekstra, di atas biaya Game Pass yang sudah dibayar.

**Kedua, streaming tanpa Game Pass.** The Verge melaporkan Microsoft membuka opsi **pay-as-you-go untuk cloud gaming tanpa langganan Game Pass** — pengguna bisa streaming game yang mereka miliki di Xbox Store di perangkat yang didukung. Seeking Alpha mencatat sisi positifnya: ini juga membuka pintu bagi pemilik Xbox One untuk memainkan game generasi baru lewat streaming tanpa perlu konsol baru.

## 📉 Seberapa Besar Dampaknya?

Microsoft membela kebijakan ini dengan data: perubahan ini "diduga hanya mempengaruhi sekitar 4% dari pelanggan" (GameRant merangkum klaim tersebut), dan dalam pernyataannya Xbox mengakui langsung motifnya — "We're introducing this model because the cost of providing cloud gaming" terus meningkat (kutipan resmi yang dikutip banyak outlet).

Yahoo Finance menambahkan konteks manajemen: **Asha Sharma, Xbox chief executive, tengah berupaya membalikkan penurunan performa divisi gaming** sejak jabatannya — pembatasan cloud ini adalah salah satu tuas monetisasi barunya. A.V. Club menyindir irama berulangnya: "kurang dari setahun setelah meluncurkan" penawaran cloud, Xbox menemukan cara baru menagih pelanggan cloud untuk cloud gaming.

Pelengkap keputusan: ini datang tak lama setelah kenaikan harga hardware Xbox — Aftermath menyebut pola penny-pinching yang kian dalam.

## 🎯 Selingan Positif: CoD Paling Underrated Masuk Game Pass

Di tengah badai kabar kebijakan, ada kabar manis: **salah satu entri Call of Duty paling underrated beberapa tahun terakhir segera bisa dimainkan oleh pelanggan Game Pass tanpa biaya tambahan** (GamingBible). Artinya: jika kamu pelanggan Game Pass (dengan sisa kuota cloud atau main di konsol), game tembak-tembakan militer dengan benchmark franchise sejak 2003 ini menunggumu.

Detail persis game dan tanggalnya bisa dicek di artikel GamingBible — yang jelas, ini masuk ke lineup gratis Game Pass.

## 🕹️ 15+ Game Baru Rilis di Xbox Hari Ini

Pure Xbox merangkum gelombang rilisan 3 September: **15+ game baru keluar di Xbox hari ini, termasuk satu rilisan day-one Game Pass**. Ditambah kabar rilisan lain: Dexter Stardust: Adventures in Outer Space resmi meluncur di Xbox (TheXboxHub), dan Fallout 76 membuka server uji "Pets" (Pspsps-TS) untuk Xbox Series dan PlayStation 5 PTS dalam beberapa pekan ke depan (Inside the Vault, Bethesda).

## 💡 Insight Hari Ini

Pola yang sama terus berulang di Xbox 2026: nilai yang dulu dijanjikan sebagai pembeda (cloud unlimited, harga lama, day-one release) satu per satu "dioptimalkan". Klaim 4% terdampak mungkin benar secara statistik — tapi psikologinya terasa lain: batas 15 jam untuk pelanggan paling mahal ($22,99/bulan) adalah tanda bahwa "ultimate" kini punya tanda bintang. Bagi pemain Indonesia yang mengandalkan cloud gaming karena keterbatasan hardware, pertimbangkan cek pola mainmu sebelum November — atau mulai hitung apakah top-up masih masuk akal dibanding konsol second-hand.
